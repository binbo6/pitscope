# 公开数据与来源说明

## 仓库包含

- 作者编写的虚构勘察说明、演示监测要求、数据分析方法与案例说明。
- 确定性公式构造的 8 个位移 CSV、示例配置与统计。
- 公开规范资料的书目信息与官方检索入口，不含其全文。
- 基于上述合成内容重新生成的截图、报告与证据附件。
- 代码、测试、架构图与作品集说明。

这些示例中的 `DEMO-M01` 等编号仅为软件演示约定。背景、坐标、阶段、位移和比较阈值都不对应实际勘察、监测、设计或 FLAC3D 求解。

## 本地资料

研究过程中使用的原始勘察报告、历史工程摘录、第三方规范 PDF、个人资料、会话数据库、模型密钥和用户上传文件保留在本地，不作为公开仓库内容。

用户通过界面导入的文档与 CSV 写入 `data/`；该目录整体被 `.gitignore` 排除。公开示例位于 `examples/`，与运行数据分开。

代码及作者编写的合成数据采用仓库 AGPL-3.0 许可。第三方依赖遵循其上游许可。公开链接不代表取得外部资料的再分发许可，也不证明规范当前有效性或项目适用性。

规范实际使用应从官方渠道取得有权使用的版本，自行核实效力与适用范围。这里仅记录检索入口，系统不会联网自动抓取标准或从目录推断允许值。
